# 協力者向け説明文

作成日: 2026-05-21

## URLと一緒に送る説明

このアプリは、退職後の生活資金を概算するための限定公開版です。

入力した年齢、資産、収入、生活費、年金などの情報は、あなたが使っているパソコンやスマートフォン内に保存されます。アプリ作成者へ入力内容を送信する機能はありません。私にも、あなたが入力した内容は見えません。

ただし、保存用ファイル、画面の画像、入力内容をあなた自身が送った場合は、その送付先に内容が伝わります。送る前に、金額や個人情報が写っていないか確認してください。

計算結果は概算です。年金、税金、社会保険、退職金、投資売却などの正式な判断には使わず、あくまで試算用として見てください。

## データの流れ

```text
アプリ置き場
アプリ本体だけを配る
        ↓
ご利用中の端末
入力・計算・保存を行う
        ↓
あなたの端末内の保存領域
入力データが保存される
```

## 送られるもの

- アプリ本体
- 画面を表示するためのHTML、CSS、JavaScript

## 送られないもの

- 入力した資産額
- 入力した収入や年金
- 入力した生活費
- 入力した家族情報
- 作成したシナリオ

## 自分で送った場合だけ伝わるもの

- 保存用ファイル
- 画面の画像
- フィードバック文面に書いた内容

## フィードバック時のお願い

次の範囲で教えてください。

- どの画面か
- 何をしようとしたか
- 期待した表示
- 実際の表示
- 分かりにくかった言葉や箇所

具体的な資産額、年金額、生年月日、住所、金融機関名などは書かなくて大丈夫です。
