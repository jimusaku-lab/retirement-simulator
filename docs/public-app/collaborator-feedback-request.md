# 協力者へのフィードバック依頼文

作成日: 2026-05-21

## 依頼文

退職後生活シミュレーションの一般向け版を試用していただきたいです。

このアプリは限定公開版です。入力した資産、収入、生活費、年金などの情報は、あなたが使っているパソコンやスマートフォン内に保存されます。アプリ作成者へ入力内容を送信する機能はありません。

ただし、保存用ファイル、画面の画像、入力内容をあなた自身が送った場合は、その送付先に内容が伝わります。フィードバックでは、具体的な金額や個人情報を書かなくて大丈夫です。

見ていただきたい点:

- 初回設定だけで試算まで進めるか
- 言葉が分かりやすいか
- 税金・社会保険の説明が不安なく読めるか
- 資産活用、やりたいことリスト、比較が分かりやすいか
- スマートフォンでも見づらくないか
- 保存先や保存用ファイルの説明が分かるか

計算結果は概算です。年金、税金、社会保険、投資判断などの正式な判断には使わず、あくまで試算用として見てください。

## 送ってほしい内容

- 使った端末: PC、スマートフォン、タブレット
- ブラウザ: Chrome、Safari、Edgeなど
- 分かりにくかった画面
- 操作に迷った箇所
- 表示が崩れた箇所
- 不安に感じた説明
- 改善した方がよいと思う点

## 送らないでほしい内容

- 実際の資産額
- 実際の年金額
- 生年月日、住所、氏名
- 金融機関名、証券会社名
- 未加工の保存用ファイル
- 金額が見える画面の画像
