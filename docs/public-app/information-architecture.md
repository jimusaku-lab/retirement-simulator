## 初回セットアップ

1. 家族

3. 収入
4. 支出
5. 前提調整
6. やりたいこと
7. 結果

### Step 1: 家族

目的: 世帯と年齢の前提を決める。

入力:

- 本人の生年月日または現在年齢
- 配偶者の有無
- 配偶者の生年月日または現在年齢
- 退職済みまたは退職予定
- シミュレーション開始年月
- 何歳まで見るか
- 何歳時点でいくら残したいか

詳細確認:

- 扶養家族を詳しく設定するか
- 国民健康保険、後期高齢者医療、介護保険を詳しく設定するか

### Step 2: 資産

目的: 現在の資産と負債を大まかに把握する。

入力:

- 現金・預金
- NISA
- iDeCo
- 課税口座
- その他運用資産
- その他資産
- 負債

詳細確認:

- 課税口座の取得原価を詳しく入れるか
- 源泉あり・源泉なしを詳しく設定するか
- 一般口座オプション等の申告対象損益を扱うか

### Step 3: 収入

目的: 退職後の主な収入を把握する。

入力:

- 年金見込み額
- 年金受給開始年齢
- 給与、パート、事業などの予定収入
- iDeCo受取予定
- 退職金または一時金の有無

詳細確認:

- iDeCo一時金、退職金、過去の退職所得を詳しく設定するか
- 世帯メンバー別の収入を詳しく分けるか

### Step 4: 支出

目的: 毎月の生活費と将来変化を把握する。

入力:

- 毎月の生活費
- 住宅費
- 医療・介護費
- 大きな予定支出
- 年齢別生活費変更

標準パターン:

- 変えない
- 70歳以降に生活費を少し下げる
- 75歳以降に医療・介護費を増やす
- 自分で設定する

### Step 5: 前提調整

目的: 結果に効く標準前提を確認する。

入力:

- インフレ率
- 資産別利回り
- 税社保の計算方法

標準パターン:

- インフレ率: 標準値を使う / 低め / 高め / 自分で設定する
- 資産別利回り: 低め / 標準 / 高め / 個別入力
- 税社保: 自動概算 / 自動概算 + 後で補正 / 詳しく設定する

### Step 6: やりたいこと

目的: 健康寿命期に使いたいお金を仮置きする。

入力:

- 旅行
- 趣味
- 家族イベント
- 学び・体験
- 住まい
- 医療・介護
- その他

金額未定でも登録できる。

### Step 7: 結果

目的: 最初の試算結果を見せ、次に調整すべき項目を案内する。

表示:

- 資産寿命
- 指定年齢時点残高
- 税社保後の使えるお金
- 税社保が重い年
- 健康寿命期の楽しみ支出余地
- 詳細設定が未完了の項目

## 表示方針

- 最初に結論を見せる
- 次に理由を見せる
- 詳細表は必要な人だけ開ける
- 税金・社会保険タブは隠さない
- 専門用語はやさしい表示名を先に出し、詳細モードで正式名称を併記する
- 詳細入力と専門補正は初回から入力欄を並べず、ウィザードで「詳しく設定する / 今は標準前提で進む」を選べるようにする
- 詳細入力と専門補正は、初回完了後もダッシュボード、入力画面、重要前提サマリーからいつでも開けるようにする
