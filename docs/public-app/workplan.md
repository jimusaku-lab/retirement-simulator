# 一般向け版 開発工程表

作成日: 2026-05-19

対象アプリ: `apps/retirement-life-planner-public`

現行安定版: `apps/retirement-life-planner`

## 1. 工程全体の考え方

一般向け版は、現行の本人・夫婦向けアプリを直接改造しない。

作業は `apps/retirement-life-planner-public` で進め、現行版は比較・回帰確認用の安定版として残す。

開発の中心は機能追加ではなく、次の再設計である。

- 初回入力体験
- 一般向けの用語
- 税金・社会保険の要約表示
- 詳細入力と専門補正の分離
- サンプルデータと実データの分離
- 保存方式と免責
- 限定公開前の品質確認

## 2. 到達目標

### 2.1 最初の到達目標

限定公開できる一般向け版を作る。

この段階では、広い一般公開や課金よりも、次を優先する。

- 実データが混入しない
- 初回ウィザードだけで試算できる
- 税社保後に使えるお金が分かる
- 詳細入力を開かなくても判断できる
- 計算が概算であることが明示されている
- 現行版の主要計算結果を壊していない

### 2.2 公開判定の基準

限定公開前に、少なくとも次を満たす。

- `npm run test:public` が成功する
- `npm run build:public` が成功する
- PC幅、タブレット幅、スマートフォン幅で主要画面が破綻しない
- サンプル世帯で初回入力から結果確認まで迷わず完了できる
- 税金・社会保険タブが要約から始まる
- 免責と対応年度が画面上で確認できる
- 実データ、個人名、QNAP共有保存前提が一般向け版に残っていない

タイムバケットは、健康寿命期の資産活用指標と接続してから一般化する。
