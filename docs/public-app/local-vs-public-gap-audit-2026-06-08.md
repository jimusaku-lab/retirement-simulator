# ローカル版・GitHub公開版 仕様差分監査

作成日: 2026-06-08

## 1. 目的

ローカル版 `apps/retirement-life-planner` と、GitHubで公開する一般向け版 `apps/retirement-life-planner-public` の差分を確認し、公開版へ実装すべき未反映項目を整理する。

ただし、ローカル版のすべてを公開版へ移植するわけではない。ローカル版には本人専用・QNAP共有・実データ復旧など、公開版に戻してはいけない機能がある。

## 2. 確認結果

確認日時: 2026-06-08

確認対象:

- ローカル版: `apps/retirement-life-planner`
- 公開版作業フォルダ: `apps/retirement-life-planner-public`
- GitHubリモート: `origin/main`

確認結果:

- `HEAD` と `origin/main` は同じコミット。
- 作業ツリーには、両アプリの `App.tsx` に未コミット変更がある。
- その未コミット変更には、初期資産タブの文言・表示優先度修正が含まれる。
- したがって、GitHub公開版には、少なくともこの未コミットUI改善がまだ反映されていない可能性が高い。

## 3. 公開版へ反映すべき差分

### 3.1 初期資産タブの表示優先度

公開版へ反映する。

内容:

- `証券・iDeCoの評価額と評価損益` を `NISA・iDeCo・特定口座などの評価額と評価損益` に変更する。
- 同カードを `詳細` ではなく `推奨` として扱う。
- 次に確認すべき対象として色付き強調できるようにする。
- 一般口座サブ口座を初期表示で畳む。
- 一般口座サブ口座は、詳細設定または原因調査時だけ展開する。

対象:

- `apps/retirement-life-planner/src/App.tsx`
- `apps/retirement-life-planner-public/src/App.tsx`

### 3.2 入力ナビゲーション強化

公開版へ反映する。

内容:

- `6/6 完了` ではなく `6項目中6項目完了` または `必須入力は完了` と表示する。
- 必須完了後の推奨項目は `次に入力` ではなく `次に確認するとよい` と表示する。
- 入力状況サマリーの次対象枠をクリック可能にする。
- クリック時に対象タブ、対象カード、最初に必要な入力欄へ移動する。
- タブの `次` バッジに、対象カードの意味を持たせる。
- ダッシュボードや結果からも入力ガイドへアクセスできるようにする。

対象:

- 主に `apps/retirement-life-planner-public/src/App.tsx`
- ローカル版にも同じ入力誘導を入れる場合は `apps/retirement-life-planner/src/App.tsx` へ反映する。

### 3.3 ローカル版と公開版で共通にしたいUI改善

公開版へ反映する。ローカル版にも残す。

- 入力カードの状態表示
- 折りたたみ初期表示
- 次カードの色付き強調
- `NISA・iDeCo・特定口座など` の一般ユーザー向け文言
- 一般口座サブ口座を詳細扱いにする方針

## 4. 公開版へ戻してはいけない差分

次はローカル版にあっても、公開版へ実装しない。

| ローカル版の機能 | 公開版での扱い | 理由 |
|---|---|---|
| QNAP共有保存 | 除外 | 本人専用・家庭内共有前提 |
| `共有保存へ保存` ボタン | 除外 | 一般ユーザーには意味が分からない |
| `実データを復旧` | 除外 | 個人用復旧導線であり実データ混入リスクがある |
| `restore=chrome5173` 復旧 | 除外 | 個人用復旧URL |
| `本人専用MVP` 文言 | 除外 | 一般公開に不適切 |
| QNAP、Chrome 5173、奥様PCなどの文言 | 除外 | 個人環境固有 |
| ローカル版の保存キー | 除外 | 公開版は専用保存キーを使う |

## 5. 公開版に既にある一般向け機能

次は公開版側に既にある、または公開版固有として残す機能。

- 初回設定ウィザード
- データの扱い説明
- GitHub Pages向けの信頼性表示
- 一般向け保存キー
- 一般向け匿名サンプル
- ブラウザ内保存データ削除
- 公開版用のサンプル移行処理

これらは、ローカル版にない場合でも公開版から削除しない。

## 6. 実装優先順位

### 優先度A

- GitHub公開版へ未コミットの初期資産タブ改善を反映する。
- 公開版で旧文言 `証券・iDeCoの評価額と評価損益` が残らないようにする。
- 一般口座サブ口座を初期表示で畳む。

### 優先度B

- 入力状況サマリーの文言とクリック導線を強化する。
- `6/6` 表記を分かりやすくする。
- `次に入力` と `次に確認するとよい` を分ける。

### 優先度C

- ローカル版と公開版で、入力誘導UIの体験差を小さくする。
- ただし、保存・復旧・共有など個人用機能は差分として残す。

## 7. 完了条件

- 公開版に、承認済みのUI改善が反映されている。
- 公開版に、QNAP共有保存や実データ復旧が戻っていない。
- ローカル版と公開版で、初期資産タブの文言と表示優先度が一致している。
- GitHub公開版で、最新ビルドが反映されている。
- `apps/retirement-life-planner-public` のテストとビルドが成功している。
- 必要に応じて `apps/retirement-life-planner` のテストとビルドも成功している。
