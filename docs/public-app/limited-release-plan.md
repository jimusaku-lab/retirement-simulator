# 限定公開運用計画

作成日: 2026-05-19

## 1. 目的

一般公開前に、初回設定、税社保表示、資産活用、シナリオ比較、保存・バックアップの分かりやすさを確認する。

計算精度の最終保証ではなく、利用者が誤解しやすい箇所、入力で迷う箇所、表示が重い箇所を見つけることを目的にする。

## 2. 対象者

限定公開は、次の条件を理解してもらえる範囲に限る。

- 計算は概算である
- 重要判断には専門家確認が必要である
- 入力内容はご利用中のパソコンやスマートフォン内に保存され、自動同期されない
- 保存用ファイルや画面の画像には家計情報が含まれる
- フィードバックは個人情報を伏せて送る

## 3. 公開範囲

限定公開では、URLやファイルを知っている人だけが利用できる範囲にする。

検索流入、広告、SNSでの広い告知は行わない。

## 4. 利用前の注意書き

配布時に次を案内する。

- このアプリは退職後生活資金の概算シミュレーションです
- 税金・社会保険は2026年度前提を中心にした概算です
- 居住地、制度改正、実際の通知書とは差が出ます
- 年金、退職金、iDeCo、資産売却、確定申告、社会保険の判断前には専門家や公的窓口で確認してください
- 入力内容はご利用中のパソコンやスマートフォン内に保存されます
- 保存用ファイルや画面の画像を送る場合は、内容を確認してください

## 5. フィードバック回収

回収する観点:

- 初回設定だけで試算まで進めたか
- インフレ率、資産別利回り、年金改定率などの前提が理解できたか
- 税社保後の余力、注意年、翌年負担が理解できたか
- やりたいことリストと特別支出化が分かりやすいか
- スマートフォン幅で使えるか
- 保存、保存用ファイル、削除方法が分かるか

## 6. 限定公開の合格条件

次を満たしたら、一般公開準備へ進める。

- 初回設定で詰まる重大な報告がない
- 税社保表示について、概算であることの誤解が少ない
- 保存先と保存用ファイルの理解に大きな混乱がない
- スマートフォン表示に致命的な崩れがない
- 個人情報や実データ混入のリスクが追加で見つかっていない

## 7. 一般公開前に追加で決めること

- 公開先URL
- プライバシーポリシーURL
- 問い合わせ先またはフォームURL
- アクセス解析やログ収集の有無
- サポート対象外の範囲
