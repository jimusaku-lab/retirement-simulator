# 一般向け版 用語表

作成日: 2026-05-19

## 表示方針

初期表示では、ユーザーが日常語として理解しやすい表示名を使う。

詳細モードでは、正式名称を併記する。

## 用語対応

| 初期表示 | 正式名称 | 表示方針 |
|---|---|---|
| 税金・社会保険 | 税・社会保険 | タブ名は「税金・社会保険」にする |
| 退職後の健康保険 | 国民健康保険 | 詳細では「国民健康保険（国保）」と併記 |
| 75歳以降の医療保険 | 後期高齢者医療 | 詳細では正式名称を出す |
| 介護保険料 | 介護保険 | 65歳以降の負担として説明 |
| 年金収入 | 公的年金等 | 詳細では公的年金等控除に触れる |
| 運用資産を売った時の税金 | 譲渡益税 | 詳細では所得税、住民税、復興特別所得税を説明 |
| 翌年の税金・社会保険に入る利益 | 申告対象損益 | 一般口座等の詳細モードで表示 |
| 収入・利益が発生した年 | 所得発生年度 | 税社保タブの詳細で表示 |
| 実際に払う年 | 支払年度 | 翌年負担の説明で表示 |
| 税金上の扶養 | 税扶養 | 詳細では配偶者控除、扶養控除を分ける |
| 取得にかかった金額 | 取得原価 | 課税口座の詳細で表示 |
| 税金が引かれる口座 | 源泉徴収あり特定口座 | 詳細では正式名称を出す |
| 自分で申告が必要になる可能性がある口座 | 源泉徴収なし、一般口座、一般口座等 | 詳細では口座種別ごとに分ける |

| 期間入力ベース | 勤続/加入開始日・終了日による重複期間概算 | 日付が揃っている場合に表示 |
| 将来の生活費変化 | 年齢別生活費変更 | 標準入力で代表パターンを出す |
| 物価上昇 | インフレ率 | 標準入力で標準値、低め、高めを出す |
| 運用利回り | 資産別利回り | 標準入力で低め、標準、高めを出す |
| 使ってよいお金 | 税社保後の使えるお金 | ダッシュボードの中心指標にする |
| 楽しみに使える余地 | 健康寿命期の楽しみ支出余地 | 資産活用ビューと接続する |
