## 実装概要

初回利用者、特に知人のお試し利用者が「サンプルを自分のデータと誤認する」「NISA積立を現在資産と誤解する」「入力ガイドで次に何を見るべきか迷う」問題を減らすため、一般公開版の初回UX、入力ガイド、サンプル状態、税務表示を調整しました。

## 主な変更内容

### 初回設定・オンボーディング

- 「現在の状態」を追加し、以下の選択肢を用意しました。
  - 退職前
  - 退職済み
  - 退職後も働く
  - 年金生活中
- 退職前の場合は、給与・退職予定・退職金を先に確認する入力順に変更しました。
- 退職済み・年金生活中の場合は、年金・iDeCo・その他収入を中心に確認する説明に変更しました。
- 初回設定を保存した際、サンプル由来の将来積立予定が残らないよう `assetContributionEvents` を空にしました。

### 初期サンプル

- 標準ケースを「入力練習用の匿名サンプル」と明示しました。
- 標準ケースの初期資産を調整し、90歳時点で目標残高を少し上回る前提にしました。
- 以前の厳しめの見え方は「厳しめケース」として別シナリオに分離しました。
- 標準ケースの将来積立予定は空にしました。
- 標準ケースが90歳目標残高を下回らないことをテストで確認する条件を追加しました。

### 入力ガイド

- 入力ガイドの文言を、必須入力完了後でも次に見る項目が分かる表現に調整しました。
- ボタン文言を以下のように改善しました。
  - `入力状況を開く`
  - `iDeCo受取を確認する`
- ヘッダーとデータタブに `初回設定をやり直す` を追加しました。

### 資産タブ

- `毎月の追加投資` を `将来の積立予定` に変更しました。
- 現在資産ではなく、開始月以降に毎月投資する予定額であることを説明しました。
- 積立予定がない場合の空状態メッセージを追加しました。
- 入力状況サマリーでは、積立予定がある場合だけ `積立予定あり` を表示するようにしました。

### 生活費タブ

- 初回設定で入力された生活費のうち、費目に分けていない分が `その他（未分類）` に入ることを説明しました。
- `その他（未分類）` が月平均生活費の50%以上の場合、確認推奨として扱うようにしました。
- 警告カードに以下の操作を追加しました。
  - `ざっくりのまま進む`
  - `費目別に分ける`
- `費目別に分ける` では、未分類額を食費・日用品・光熱費・通信費へ概算配分します。

### 特別支出タブ

- 上部に `やりたいことから作る` カードを追加しました。
- 旅行・趣味・家族イベントなどを資産活用のタイムバケットで整理してから、必要なものだけ特別支出へ変換できる導線を追加しました。
- 特別支出がない、または楽しみカテゴリがない場合は、このカードを強調表示します。

### 税・社会保険

- 確定申告アドバイスで、注意・確認が必要な年度を先に表示するようにしました。
- `申告不要制度の可能性が高い` 年度は連続年度ごとにまとめて折りたたみ表示にしました。
- 全年度の判定表は `全年度の判定表を開く` の詳細表示に移しました。

### 結果タブ

- 将来の積立予定で原資不足がある場合、結果タブから `将来の積立予定を確認` へ移動できる導線を追加しました。
