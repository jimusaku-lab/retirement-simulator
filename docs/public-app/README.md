# 一般向け版 設計資料

このディレクトリは、退職後生活シミュレーションアプリの一般向け版に関する設計資料を置く場所です。

アプリ本体は `apps/retirement-life-planner-public` で開発します。現行の本人・夫婦向け安定版 `apps/retirement-life-planner` とは分離します。

## 資料

- `requirements.md`: 一般向け版の要求整理
- `information-architecture.md`: 画面構成と導線
- `input-classification.md`: 入力項目の標準・詳細・専門分類
- `tax-social-policy.md`: 税金・社会保険の扱い方
- `current-app-inventory.md`: 現行版から一般向け版への棚卸し
- `migration-policy.md`: 流用、再設計、除外の方針
- `glossary.md`: 一般向け表示名と正式名称の対応
- `sample-households.md`: 匿名サンプル世帯と初期シナリオ案
- `data-storage-policy.md`: 保存方式、データ混在防止、匿名サンプル化方針
- `onboarding-implementation-notes.md`: 初回設定ウィザードの実装メモ
- `workplan.md`: 一般向け版の開発工程表
- `release-checklist.md`: 限定公開・一般公開前の確認項目
