# 一般向け版 匿名サンプル世帯

作成日: 2026-05-19

## 方針

一般向け版では、個人利用に見えるサンプルを避ける。

初期表示では、投資手法や特定の家族事情に寄りすぎない匿名サンプルを使う。

## サンプルA: 退職前夫婦世帯

用途: 初期表示の標準サンプル候補。

前提:

- 本人: 58歳
- 配偶者: 57歳
- 退職予定: 60歳
- シミュレーション終了: 95歳
- 90歳時点で残したい金額: 500万円

資産:

- 現金・預金: 1,200万円
- NISA: 800万円
- iDeCo: 600万円
- 課税口座: 700万円
- その他資産: 0円
- 負債: 0円

収入:

- 本人年金見込み: 年180万円
- 配偶者年金見込み: 年120万円
- 60歳から65歳までの給与・パート: 月10万円
- iDeCo受取: 65歳から年金形式または一時金を選択

支出:

- 毎月生活費: 32万円
- 70歳以降: 生活費を5%下げる
- 75歳以降: 医療・介護費を月2万円増やす

前提:

- インフレ率: 標準
- 資産別利回り: 標準
- 税社保: 自動概算

やりたいこと:

- 旅行: 60歳から70歳まで年30万円
- 家族イベント: 65歳、70歳に各30万円
- 住まいの修繕: 68歳に120万円

- NISA: 500万円

- 課税口座: 400万円
- その他資産: 0円

## サンプルC: 詳細投資あり世帯

用途: 詳細モードの確認用。初期表示には使わない。

前提:

- 課税口座の取得原価あり
- 源泉あり、源泉なしの比較あり
- 一般口座等の申告対象損益あり
- iDeCo一時金と退職金あり
- 税社保の補正あり

注意:

このサンプルは、税社保詳細、申告対象損益、退職所得控除、取得原価の検証に使う。

一般ユーザーの初回サンプルとしては出さない。

## 初期シナリオ案

初期表示で用意するシナリオ:

1. 標準ケース
2. 生活費を少し抑える
3. 年金受給を早める
4. 年金受給を遅らせる
5. 健康寿命期に楽しみ支出を追加する
6. 利回りを低めに見る

初期表示から外すシナリオ:

- 月10万円追加入金
- CFD
- 米国株オプション
- 一般口座オプション中心のケース
