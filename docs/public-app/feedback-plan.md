# 問い合わせ・フィードバック導線

作成日: 2026-05-19

## 1. 方針

限定公開中は、専用の不特定多数向け問い合わせフォームを前提にせず、配布者が指定する連絡先でフィードバックを受ける。

一般公開前に、専用フォームまたは専用メールアドレスを用意する。

## 2. 限定公開中の導線

アプリ内マニュアルでは、次の案内にする。

- 問い合わせは配布時に案内された連絡先へ送る
- 画面名、操作内容、期待した結果、実際の表示を送る
- JSONやスクリーンショットには家計情報が含まれるため、送付前に内容を確認する

## 3. 推奨フィードバック項目

報告時は、可能な範囲で次を集める。

- 利用環境: PC、スマートフォン、ブラウザ
- 画面名: ダッシュボード、初回設定、資産活用、比較、データなど
- 操作内容
- 期待した結果
- 実際の結果
- 重要度: 試算できない、表示が分かりにくい、文言が不安、軽微な改善
- 個人情報を伏せたスクリーンショット

## 4. 送付を避けてもらう情報

原則として、次の送付は避けてもらう。

- 生年月日、住所、氏名などの本人特定情報
- 実額がそのまま入った資産・年金・収入情報
- 未加工のJSONバックアップ
- 金融機関、証券会社、年金通知書、税通知書の原本画像

必要な場合は、目的と範囲を確認してから受け取る。

## 5. 一般公開時の候補

一般公開時は、次のいずれかを用意する。

- 専用フォーム
- 専用メールアドレス
- GitHub Issuesなどの公開課題管理

家計情報が混ざる可能性があるため、公開課題管理を使う場合は、個人情報や金額を投稿しない注意を強く表示する。

## 6. アプリ内での表記

現時点のアプリ内表記:

> 限定公開中は、配布時に案内された連絡先へ、画面名、操作内容、期待した結果、実際の表示を送ってください。

一般公開時には、上記を具体的なフォームURLまたはメールアドレスに置き換える。
