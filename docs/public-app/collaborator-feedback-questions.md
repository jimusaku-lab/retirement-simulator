# 協力者フィードバック質問項目

作成日: 2026-05-21

Googleフォームまたはメールで使う質問案。

## 基本

1. 使った端末を教えてください。
   - PC
   - スマートフォン
   - タブレット

2. 使ったブラウザを教えてください。
   - Chrome
   - Safari
   - Edge
   - その他

3. 初回設定だけで試算まで進めましたか。
   - 進めた
   - 途中で迷った
   - 進めなかった

4. 迷った画面があれば教えてください。

5. 分かりにくい言葉があれば教えてください。

## 安心説明

6. 入力データがブラウザ内に保存される説明は分かりましたか。
   - 分かった
   - だいたい分かった
   - 分かりにくかった

7. 「作成者へ入力内容を送信する機能はない」という説明で安心できましたか。
   - 安心できた
   - もう少し説明がほしい
   - 不安が残った

8. 不安が残った場合、どの説明が足りませんでしたか。

## 画面別

9. ダッシュボードは分かりやすかったですか。

10. 税金・社会保険の説明は分かりやすかったですか。

11. 資産活用、やりたいことリストは分かりやすかったですか。

12. シナリオ比較は分かりやすかったですか。

13. 保存、保存用ファイル、削除方法は分かりやすかったですか。

## 改善

14. 特に良かった点があれば教えてください。

15. 改善した方がよい点があれば教えてください。

16. 今後も使いたいと思いましたか。
   - 使いたい
   - 条件による
   - 使わないと思う

注意: 実際の資産額、年金額、生年月日、住所、氏名、金融機関名は書かないでください。
