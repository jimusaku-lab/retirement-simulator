# 実装担当向けプロンプト: 公開版マニュアルに初期化手順を追加

作成日: 2026-06-10

## 対象

- アプリ: 一般向け公開版
- 対象ディレクトリ: `apps/retirement-life-planner-public`
- 主な修正候補: `apps/retirement-life-planner-public/src/App.tsx`
- 主な対象コンポーネント: `ManualSection`

## 背景

公開版には、データタブに `この端末の入力データを削除` ボタンがある。

ただし、マニュアル上では「試しに入れた数字を消して、一番最初の状態からやり直したい時に何をすればよいか」が、ユーザー視点で十分に明示されていない。

現状のマニュアルには、保存先やデータ削除への簡単な説明はあるが、目的別の案内としては弱い。

初めて試す友人、共有端末で試した人、過去のお試し入力を消したい人が迷わないように、マニュアル内に明確な手順を追加する。

## 実装方針

マニュアル内に `最初からやり直すには` という説明カードを追加する。

配置は、ユーザーが探しやすい位置を優先する。

推奨配置:

- `プライバシーとフィードバック` の直後
- または `保存と復元` カードの近く

既存の `データの扱い` モーダル、データタブ内の文言と矛盾しないようにする。

## 追加する内容

次の内容がユーザーに伝わるようにする。

1. 上部メニューの `データ` を開く。
2. `この端末の入力データを削除` を押す。
3. 確認ダイアログを承認する。
4. このブラウザに保存された入力データと履歴バックアップが削除される。
5. 削除後は、初期サンプルと初回設定からやり直せる。
6. 過去に作成した保存用JSONファイルは自動では削除されない。
7. 不要な保存用JSONファイルは、端末上で別途削除する必要がある。

## 表現ルール

- `localStorage` などの技術用語は使わない。
- 「このブラウザ」「この端末」という表現を使う。
- 「削除されるもの」と「削除されないもの」を明確に分ける。
- 初めて触る人が、操作前に影響範囲を理解できる文言にする。

## `サンプルに戻す` との違いも説明する

データタブには `サンプルに戻す` と `この端末の入力データを削除` の両方があるため、マニュアル内で違いを短く説明する。

- `サンプルに戻す`: 現在の入力状態をサンプルへ戻す操作。完全な初回状態に戻す目的ではない。
- `この端末の入力データを削除`: このブラウザに保存された入力データと履歴バックアップを削除し、初回状態からやり直す操作。

## 文言案

必要に応じて既存UIに合わせて調整してよい。

```tsx
<Card>
  <CardHeader>
    <CardTitle>最初からやり直すには</CardTitle>
    <CardDescription>試しに入れた数字を消して、初回状態から入力し直す方法です。</CardDescription>
  </CardHeader>
  <CardContent className="space-y-3 text-sm leading-7 text-muted-foreground">
    <p>
      上部メニューの「データ」を開き、「この端末の入力データを削除」を押すと、
      このブラウザに保存された入力データと履歴バックアップを削除できます。
    </p>
    <p>
      削除後は、初期サンプルと初回設定からやり直せます。確認画面が表示されるため、
      内容を確認してから実行してください。
    </p>
    <p>
      過去に作成した保存用ファイルは自動では削除されません。不要な保存用JSONファイルは、
      端末上で別途削除してください。
    </p>
    <p>
      「サンプルに戻す」は現在の入力内容をサンプルへ戻す操作です。
      完全に初回状態から試したい場合は、「この端末の入力データを削除」を使ってください。
    </p>
  </CardContent>
</Card>
```

## 完了条件

- 公開版マニュアルに `最初からやり直すには` が表示される。
- 初めて使う人が、試し入力を消して初期状態から再開する手順を迷わず理解できる。
- `サンプルに戻す` と `この端末の入力データを削除` の違いが分かる。
- 保存用JSONファイルは自動削除されないことが分かる。
- 公開版のビルドが通る。
- 可能なら画面で `マニュアル` タブを開き、追加文言が表示されることを確認する。

## 実装後の報告に含めること

- 修正したファイル
- 追加したマニュアル見出し
- ビルド確認結果
- 画面確認をした場合は、その確認内容
