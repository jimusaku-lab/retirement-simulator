## 背景

一般向け公開版は、初回UX改善により、退職前/退職済みの分岐、将来の積立予定、生活費未分類、資産活用から特別支出への導線が改善済みです。

次の課題は、友人テスト前に「退職済み・退職直前の人向け」に見えすぎる印象を緩和し、50歳前後の現役会社員にも自然に使える入口へ広げることです。

今回の目的は、現役ユーザーが次を判断しやすくすることです。

- 今後10年から15年働いた場合、60歳・65歳時点でいくら資産ができるか
- 何歳で早期リタイア、仕事量の削減、セカンドキャリアが現実的か
- 教育費、住宅ローン、親の介護などを入れても成立するか
- 家族旅行、趣味、学びなどの体験支出をいつ・いくら入れられるか

## 実装優先順位

### P0: 友人テスト前に実装

1. 初回設定に `今回知りたいこと` を追加する。
2. `退職前` ユーザーの入力順と説明を現役向けにする。
3. ダッシュボードに退職前ユーザー向けカードを追加する。
4. 初期シナリオを現役ユーザーにも分かりやすくする。
5. ライフイベントテンプレート最小版を追加する。
6. 入力状況サマリーを `次の入力` だけでなく `次の意思決定` として表示する。

### P1: 友人テスト後に拡張

1. ライフイベントテンプレートの詳細化。
2. 目的別ダッシュボード切替。
3. セカンドビジネス、役職定年、収入減の詳細入力。
4. NISA、iDeCo、課税口座の資産形成ビュー強化。
5. シナリオ比較の説明強化。

## P0 実装詳細

### 1. 初回設定に `今回知りたいこと` を追加

対象候補:

- `apps/retirement-life-planner-public/src/components/OnboardingWizard.tsx`

追加する選択肢:

- 何歳時点でいくら資産ができるか知りたい
- 早期リタイアできる年齢を見たい
- 仕事を減らす、またはセカンドビジネスを始める前提で見たい
- 教育費、住宅ローン、親の介護などを含めて見たい
- 家族旅行、趣味、学びなどにいくら使えるか見たい
- 年金、iDeCo、退職金の受け取り方を見たい

複数選択できる形が望ましい。

保存先は既存データ構造への影響を最小化する。

実装方針:

- まずは `householdProfile` または公開版専用のUI状態に `planningGoals` のような配列を追加する。
- 互換性のため、未定義時は空配列扱いにする。
- 目的選択は計算結果そのものを変えず、表示優先順位と入力ガイドに使う。

受け入れ条件:

- 初回設定の冒頭で、ユーザーが今回の目的を選べる。
- 選択後、説明文が目的に合わせて変わる。
- 既存データを読み込んでも落ちない。

### 2. `退職前` ユーザーの入力順を現役向けにする

現状の `退職前` 分岐は残しつつ、文言と順序を強める。

退職前ユーザーで優先する入力:

1. 現在の給与、賞与、仕事収入
2. 毎月の積立、NISA、iDeCo
3. 何歳まで今の働き方を続けるか
4. 教育費、住宅ローン、親の介護
5. 家族旅行、趣味、学びなどの体験支出
6. 年金、退職金、iDeCo受取

受け入れ条件:

- 50歳前後の現役会社員が、年金より先に現在収入・積立・働き方を確認できる。
- 年金や退職金の入力は消さず、後半の確認項目として残る。

### 3. ダッシュボードに退職前ユーザー向けカードを追加

対象候補:

- `apps/retirement-life-planner-public/src/App.tsx`

追加表示:

- 60歳時点の見込み資産
- 65歳時点の見込み資産
- 仕事をやめても成立しそうな年齢
- 健康なうちに楽しみに使える年額
- ライフイベント支出が重なる注意年

実装方針:

- 既存の月次/年次シミュレーション結果から、本人年齢が60歳、65歳になる時点の残高を拾う。
- `仕事をやめても成立しそうな年齢` はP0では簡易表示でよい。厳密な最適化は不要。
  - 例: 現在シナリオで資産寿命が目標年齢以上なら、収入終了年齢を参考表示する。
  - 厳密判定が難しい場合は `シナリオ比較で確認` へ誘導する。
- ライフイベント支出が重なる注意年は、特別支出の年別合計が大きい年を表示する。

受け入れ条件:

- 退職前ユーザーのダッシュボードで、資産寿命だけが主役にならない。
- 60歳、65歳時点資産が確認できる。

### 4. 初期シナリオを現役ユーザー向けにする

対象候補:

- `apps/retirement-life-planner-public/src/data/sampleData.ts`

シナリオ案:

- 標準: 今の働き方と積立を継続
- 早期リタイア: 60歳で仕事をやめる
- セカンドキャリア: 60歳以降は月10万円から20万円の収入
- 楽しみ優先: 55歳から65歳に旅行・体験支出を増やす
- 安全重視: 支出を抑え、90歳時点残高を厚めに残す

既存の年金繰上げ、年金繰下げシナリオは残してよいが、初期表示では優先度を下げる。

受け入れ条件:

- 初めて使う人が、比較タブで人生パターンの違いを理解できる。
- シナリオ名が年金中心に偏りすぎない。

### 5. ライフイベントテンプレート最小版を追加

対象候補:

- `apps/retirement-life-planner-public/src/App.tsx`
- 必要に応じて新規コンポーネント

P0テンプレート:

- 教育費
- 住宅ローン・住まい
- 親の介護・支援
- 家族旅行・体験

実装方針:

- 新しい計算エンジンは作らない。
- テンプレートは入力補助として実装し、既存の特別支出、生活費変更、収入イベント、負債入力へ変換する。
- まずは入力カードまたはモーダルでよい。
- 登録後は、通常の特別支出などとして編集できる。
- 由来が分かるように `ライフイベント由来`、`教育費`、`住宅`、`親の介護` などのラベルを付ける。

#### 教育費テンプレート

入力:

- 対象者名
- 開始年月
- 終了年月
- 毎月費用
- 一時金
- 必須支出 / 余裕があれば

変換:

- 毎月費用は年次または月次の特別支出へ展開
- 一時金は単発の特別支出へ変換

#### 住宅ローン・住まいテンプレート

入力:

- 毎月返済または家賃
- 返済終了年月
- 固定資産税などの年額
- リフォーム予定年月
- リフォーム一時金

変換:

- 月額は住居費または生活費変更へ反映
- 返済終了後は住居費減少イベントを作る
- リフォームは特別支出へ変換

#### 親の介護・支援テンプレート

入力:

- 対象
- 開始年月
- 想定期間
- 毎月支援額
- 一時金
- 年間帰省費
- 確度: 確定 / 可能性あり / 未定

変換:

- 確定は特別支出へ反映
- 可能性ありは、標準シナリオではなく別シナリオ作成候補として扱うのが望ましい

#### 家族旅行・体験テンプレート

入力:

- やりたいこと名
- 実施時期
- 年額または一時金
- 優先度

変換:

- タイムバケットへ追加
- 実行するものだけ特別支出へ変換できるようにする

受け入れ条件:

- 教育費、住宅ローン、親の介護が入力候補として見落とされにくい。
- テンプレートから作った支出が試算に反映される。
- 体験支出は資産活用のタイムバケットとつながる。

### 6. 入力状況サマリーを `次の意思決定` にする

対象候補:

- `apps/retirement-life-planner-public/src/App.tsx`

文言例:

- 次に確認: 何歳まで今の働き方を続けるか
- 次に確認: 教育費の予定
- 次に確認: 住宅ローン終了年月
- 次に確認: 親の介護・支援の可能性
- 次に確認: 家族旅行・体験支出

受け入れ条件:

- 単なる入力チェックではなく、ユーザーが次に考えるべき判断として表示される。
- クリックで該当カードへ移動し、枠色やラベルで強調される。

## P1 実装詳細

P1はP0実装後、友人テストの反応を見て進める。

候補:

- 車、子どもの独立、結婚支援、住み替えテンプレート
- 親の介護による収入減、時短勤務、介護離職
- セカンドビジネスの初期費用、赤字期間、収入成長
- 目的別ダッシュボード切替
- NISA年間枠、iDeCo拠出、課税口座売却の資産形成ビュー
- シナリオ比較に `何が効いたか` の説明を追加

## 実装工程

### Phase 1: データ設計と互換性確認

- `planningGoals` など目的選択の保存場所を決める。
- ライフイベント由来ラベルの持ち方を決める。
- 既存保存データの読み込み互換性を確認する。

### Phase 2: 初回設定と入力ガイド

- 初回設定に `今回知りたいこと` を追加する。
- 退職前ユーザーの説明と入力順を調整する。
- 入力状況サマリーに `次の意思決定` を追加する。

### Phase 3: ダッシュボード

- 60歳、65歳時点資産カードを追加する。
- 退職前ユーザーでは資産寿命の優先度を下げる。
- ライフイベント注意年を表示する。

### Phase 4: ライフイベントテンプレート

- 教育費テンプレート
- 住宅ローン・住まいテンプレート
- 親の介護・支援テンプレート
- 家族旅行・体験テンプレート

### Phase 5: 初期シナリオ

- 現役会社員向けシナリオ名と前提へ調整する。
- 比較タブで違いが分かることを確認する。

### Phase 6: QA

必ず実行:

```bash
npm --prefix apps/retirement-life-planner-public run test -- src/lib/simulation.test.ts
npm --prefix apps/retirement-life-planner-public run build
git diff --check -- apps/retirement-life-planner-public
```

ブラウザ確認:

- 初回設定で `今回知りたいこと` が選べる。
- 退職前ユーザーで、給与、積立、働き方、ライフイベントが先に案内される。
- ダッシュボードで60歳、65歳時点資産が見える。
- 教育費、住宅ローン、親の介護テンプレートから支出を作れる。
- 家族旅行・体験テンプレートが資産活用ビューとつながる。
- 比較タブで `今の働き方を継続`、`早期リタイア`、`セカンドキャリア`、`楽しみ優先`、`安全重視` が分かる。
- PC幅とスマートフォン幅で、カードが画面を覆いすぎない。
