# 実装担当向けプロンプト: 一般向け版 入力ナビゲーション強化

作成日: 2026-06-08

## 背景

一般向け版に `入力状況サマリー` と `次` バッジは入ったが、初回ユーザーにはまだ弱い。

スクリーンショット上の課題:

- `必須入力 6/6 完了` の意味が分からない。
- `次に入力 iDeCo受取` と表示されても、iDeCo受取がどこにあるか一目で分からない。
- `次` バッジが収入タブにあるが、そこを押すと何が起きるか分かりにくい。
- 入力状況サマリー自体が、ユーザーがたまたま `結果` などを押した時に見つかる状態に見える。
- 初回ユーザーが、1つ入力した後に次の入力欄まで自然に進める導線としては弱い。

## 実装方針

### 1. `6/6` 表記を分かりやすくする

現状:

```text
必須入力
6/6 完了
```

変更:

```text
必須入力は完了
6項目すべて入力済み
```

未完了がある場合:

```text
必須入力
4項目中2項目完了
未入力: 生活費、公的年金
```

追加:

- `内訳を見る` を置く。
- 内訳に、必須カード名と状態を表示する。
- `必須入力` と `確認推奨` を混ぜない。

### 2. 必須完了後の推奨項目は `次に確認するとよい` にする

現状:

```text
次に入力
iDeCo受取
```

必須入力がすべて完了しており、iDeCo受取が推奨確認の場合は、次の表示にする。

```text
次に確認するとよい
iDeCo受取
iDeCo残高600万円の受取方法が未確認です
```

ルール:

- 必須未完了なら `次に入力`
- 必須完了 + 推奨項目ありなら `次に確認するとよい`
- 専門項目なら `必要なら確認`

### 3. 次対象の枠全体をクリック可能にする

入力状況サマリー内の `次に入力` / `次に確認するとよい` の枠は、表示だけでなくクリック対象にする。

クリック動作:

1. 対象カードのタブへ切り替える。
2. 対象カードを展開する。
3. 対象カードへスクロールする。
4. 可能なら最初に必要な入力欄へフォーカスする。
5. 対象カードを数秒間強調する。

iDeCo受取の場合:

- `収入` タブへ切り替える。
- `iDeCo受取` カードを開く。
- `iDeCo受取方法` セレクト、または最初の未確認入力欄へフォーカスする。

ボタン文言:

- 必須未完了: `ここを入力する`
- 推奨確認: `ここを確認する`
- iDeCo: `iDeCo受取を確認する`

### 4. タブの `次` バッジを分かりやすくする

現状の `次` バッジは、意味が弱い。

改善:

- 対象タブには `次` バッジを残す。
- hover または aria-label で `次: iDeCo受取` のように説明する。
- タブを押した時は、単にタブ先頭へ行くのではなく、対象カードへスクロールする。
- 対象カードが別タブにある場合、サマリー側にも `収入タブにあります` と表示する。

表示例:

```text
次に確認するとよい
iDeCo受取
収入タブにあります
```

### 5. 入力状況サマリーへのアクセスを強化する

入力状況サマリーは、ユーザーが偶然見つけるものにしない。

実装:

- `安全性シミュレーション` の全サブタブ上部に表示する。
- `ダッシュボード` と `結果` には、簡易版を出す。
- 確認推奨が残っている時は、ダッシュボード先頭またはヘッダー付近に `次に確認: iDeCo受取` の導線を出す。
- `入力ガイド` ボタンを押すと、入力状況サマリーへスクロールする。

簡易版の表示例:

```text
入力ガイド
必須入力は完了。次に iDeCo受取 を確認すると試算の精度が上がります。
[iDeCo受取を確認する]
```

### 6. 視覚強調を強くする

次対象カードは、枠色だけではなく、ラベルも出す。

表示:

- 枠: アンバー系
- ラベル: `次に確認`
- 補足: `iDeCo残高600万円の受取方法が未確認です`

強調は、常時強すぎると邪魔になるため、スクロール直後は強く、数秒後は控えめにする。

## QA

必ず実行:

```bash
npm --prefix apps/retirement-life-planner-public run test -- src/lib/simulation.test.ts
npm --prefix apps/retirement-life-planner-public run build
```

ブラウザ確認:

- `http://127.0.0.1:5176/`
- PC幅
- 390px前後のスマートフォン幅

確認項目:

- `6/6 完了` ではなく、`6項目すべて入力済み` など意味が分かる表記になっている。
- 必須が完了している場合、推奨項目は `次に入力` ではなく `次に確認するとよい` と表示される。
- `iDeCo受取` の枠全体をクリックすると、`収入` タブのiDeCo受取欄へ移動する。
- 対象カードが展開され、最初に必要な入力欄へスクロールまたはフォーカスされる。
- `収入` タブの `次` バッジが、次対象が収入内にあることを示す。
- ダッシュボードまたは結果から、入力状況サマリーまたは次対象へ移動できる。
- 色だけで意味を伝えず、ラベルと説明文が併記されている。
