# 実装担当向けプロンプト: 初期資産タブの表示優先度と文言修正

作成日: 2026-06-08

## 背景

初期資産タブで、一般口座サブ口座の詳細カードが大きく表示され、ユーザーにはそこが主な入力対象に見えてしまっている。

一方、一般ユーザーがまず確認すべきなのは、NISA、iDeCo、特定口座などの評価額と評価損益である。

現在の見出し `証券・iDeCoの評価額と評価損益` は、NISAが主対象であることが伝わりにくい。より分かりやすく、`NISA・iDeCo・特定口座などの評価額と評価損益` に変更する。

## 対象

両方に反映すること。

- ローカル版: `apps/retirement-life-planner`
- 公開版: `apps/retirement-life-planner-public`

主に確認するファイル:

- `apps/retirement-life-planner/src/App.tsx`
- `apps/retirement-life-planner-public/src/App.tsx`

変更しない:

- 税額計算ロジック
- シミュレーション計算ロジック
- 保存データ構造
- iDeCo退職所得控除ロジック

## 実装方針

### 1. 見出しを変更する

現状:

```text
証券・iDeCoの評価額と評価損益
```

変更:

```text
NISA・iDeCo・特定口座などの評価額と評価損益
```

対象:

- 公開版
- ローカル版
- 初期資産タブ内のカード見出し
- シナリオ反映や同期メニューで同じ意味の `証券・iDeCo評価額` がある場合は、短くても `NISA・iDeCo等の評価額` へ寄せる

### 2. 補助文を分かりやすくする

現状の補助文:

```text
マネーフォワードの評価額と評価損益を入れてください。取得原価は自動計算し、特定口座と一般口座の取り崩し課税に使います。
```

変更案:

```text
NISA、iDeCo、特定口座などについて、マネーフォワード等の評価額と評価損益を入力します。取得原価は自動計算し、課税口座の取り崩し時の税額概算に使います。
```

ポイント:

- NISAを先に出す。
- iDeCo、特定口座も明示する。
- `証券` という広い言葉だけにしない。
- 一般口座サブ口座を主対象に見せない。

### 3. 初期資産タブでの表示優先度を変える

初期資産タブの表示優先度:

1. 現金・預金・負債などの現在資産
2. `NISA・iDeCo・特定口座などの評価額と評価損益`
3. その他の詳細設定
4. 一般口座（申告対象運用）のサブ口座

実装:

- `NISA・iDeCo・特定口座などの評価額と評価損益` を、確認推奨または次対象として強調できるようにする。
- 対象カードの枠色はアンバー系、ラベルは `確認推奨` または `次に確認` とする。
- 入力状況サマリーから `取得原価・評価損益` へ移動する場合、このカードへスクロールする。

### 4. 一般口座サブ口座は畳む

一般口座（申告対象運用）のサブ口座は、初期表示では畳む。

表示:

```text
一般口座（申告対象運用）のサブ口座
詳細設定。通常は閉じたままで構いません。
[開く]
```

展開条件:

- ユーザーが明示的に `開く` を押した時
- 一般口座サブ口座の詳細管理を有効にしている時
- 結果、税・社会保険、比較などから原因調査でこのカードが指定された時

避けること:

- 初期資産タブを開いた時点で、一般口座サブ口座のフォーム全体を大きく表示しない。
- `使わない` になっている一般口座オプション用の詳細入力を主画面に出し続けない。

### 5. 両バージョンで差を作らない

今回の変更は一般向けだけでなく、ローカル版にも同じく入れる。

確認:

- `apps/retirement-life-planner/src/App.tsx`
- `apps/retirement-life-planner-public/src/App.tsx`

両方で、見出し、補助文、折りたたみ初期状態、強調ラベルが一致していること。

- PC幅とスマートフォン幅で表示が崩れない。
