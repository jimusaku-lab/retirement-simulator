# 自分用アプリ完成版 改善提案レポート

作成日: 2026-05-16  
対象アプリ: 退職後生活シミュレーション  
対象範囲: 今回は「本人専用アプリとして完成度を上げる」ことを目的とする。第三者・他社が初めて使うための汎用化、初回オンボーディング、説明付きウィザード化は後続バージョンで扱う。

## 1. 今回の改善方針

今回の完成版では、機能を増やすよりも、現在すでに計算されている重要な結果を誤解なく読める状態にすることを優先する。

特に重要なのは次の3点。

1. 「資産活用額」と「取り崩し」を混同しない表示にする
2. シナリオごとの差分を、結果を見る前に確認できるようにする
3. ダッシュボードと比較タブを、本人が意思決定に使う指標へ絞る

## 2. 現状評価

計算ロジック自体は、本人専用アプリとしてはかなり整理されている。

月次単位で、収入、生活費、税・社会保険、特別支出、iDeCo受取、NISA追加投資、普通口座オプション利益、普通預金への戻し、資産残高を積み上げている。テストも現状すべて通っている。

一方で、画面上の言葉と数字の関係がまだ難しい。特に、ユーザーが次のように誤解しやすい。

- 「資産活用額」は、自由に使えるお金なのか、資産から補った不足額なのか
- 「取り崩し」は、生活費の不足なのか、追加投資の原資不足も含むのか
- シナリオ名に「パートなし」とある場合、どの年のどの収入が消えているのか
- オプション利益が増えたのに、NISA実行額・未実行額・残り枠がどう動くのか
- チャートの縦軸スケール差によって、資産額が実際より良く見える/悪く見えることがある

このため、計算そのものよりも「読み方の設計」が今回の主課題。

## 3. 最優先改善: シナリオ差分パネル

### 3.1 目的

比較結果を見る前に、「このシナリオは基準と何が違うのか」を確認できるようにする。

これにより、残高やチャートの差が出たときに、原因を探すために収入タブや特別支出タブを何度も見に行く必要がなくなる。

### 3.2 基準シナリオ

基準は固定ではなく、任意に選べる形がよい。

比較タブ上部に以下のような選択欄を置く。

```text
基準シナリオ: [ 年金60才（夫婦）IDECO10年 ▼ ]
```

この基準シナリオに対して、現在選択中シナリオ、または比較対象シナリオとの差分を表示する。

### 3.3 表示する差分

差分パネルで見るべきものは、結果の差ではなく、入力条件の差。

最低限、以下を出す。

| 分類 | 表示例 |
| --- | --- |
| 収入 | 妻パート: 基準 2026/04〜2027/12、対象 2026/04〜2026/12 |
| 収入 | 米国株オプション: 基準なし、対象 月10万円 2026/07〜2040/12 |
| 収入 | CFD: 両方あり 月2万円 |
| iDeCo | 基準 5年受取、対象 10年受取 |
| NISA | 月額、開始終了、未実行繰越設定、生涯枠使用済み額の違い |
| 特別支出 | 追加、削除、金額変更、カテゴリ変更 |
| 生活費 | 月額合計、年齢別調整、同居状態変更の違い |
| 税・社会保険 | 自動/手入力/自動+補正の違い |
| 普通口座オプション | 口座内積上、普通預金へ戻す設定、最低維持額、終了後戻しの違い |

### 3.4 表示場所

推奨は2か所。

1. 比較タブ上部  
   全シナリオ比較の基準として使う。

2. ダッシュボード上部  
   現在選択中シナリオが、基準シナリオと何が違うかを短く表示する。

ダッシュボードでは詳細表ではなく、3〜5行程度の要約にする。

例:

```text
基準との差分
- 妻パート: 2027年分なし
- 米国株オプション: 月10万円を口座内積上
- iDeCo受取: 5年 → 10年
```

## 4. ダッシュボード改善

### 4.1 残すべきカード

本人用ダッシュボードで残すべき主要カードは以下。

1. 現在資産
2. 資産寿命 / 90歳残高
3. 60〜72歳 資産活用額
4. 72歳時点残高
5. 60〜72歳 楽しみ支出
6. 60〜72歳 生活・税社保支出
7. 60〜72歳 その他特別支出
8. NISA実行額 / 残り枠

この8つは現在の方向性でよい。

### 4.2 表示名を調整した方がよいもの

#### 資産活用額

現在の意味は次の通り。

```text
現金収入 + 普通口座から現金/普通預金へ戻した額
- 生活費
- 税・社会保険
- 譲渡益税
- iDeCo源泉
- 特別支出
- iDeCo手数料
= 期間中の現金収支

これがマイナスなら、その不足分を「資産活用額」としてプラス表示
```

ここでは追加投資は差し引かない。これは正しい。

ただし、カードの補足文はもう少し短くする。

推奨:

```text
生活費・税社保・特別支出を、現金収入だけで賄えず資産で補った額
```

#### 生活・税社保支出

現状は譲渡益税やiDeCo源泉も含むため、厳密には「生活費と税社保の実支出」だけでは少し不足する。

推奨:

```text
生活・税社保・源泉/譲渡益税支出
```

またはカード名は現状維持でも、補足を以下にする。

```text
生活費、税社保、譲渡益税、iDeCo源泉の合計
```

### 4.3 不要または抑制した方がよい情報

本人用ダッシュボードでは、以下はメインカードに出さなくてよい。

- 60〜72歳の年平均余力
- 60〜72歳の最低流動資金
- 流動資金最低保持額
- 目標残高そのもの
- 詳細な不足補填売却元

これらは認知済みの前提、または詳細確認用の情報。ダッシュボードではなく詳細折りたたみ、結果タブ、比較タブに置く。

## 5. チャート改善

### 5.1 現在の問題

ダッシュボードの「資産残高と取り崩しの推移」は便利だが、次の誤解を生みやすい。

- シナリオごとに縦軸スケールが変わり、見た目の高さで誤解しやすい
- 「取り崩し」に、生活資金不足だけでなく追加投資原資不足も含まれる
- 「資産活用額」と「年間取り崩し」が同じ意味に見える

### 5.2 改善案

#### チャート1: 資産残高推移

年末資産残高だけを見るチャートにする。

比較用には、複数シナリオを同一スケールで重ねる。

#### チャート2: 資産活用ウォーターフォール

60〜72歳の期間について、以下をウォーターフォールで表示する。

```text
現金収入
+ 普通口座から現金/普通預金へ戻した額
- 生活費
- 税社保・源泉/譲渡益税
- 特別支出
- iDeCo手数料
= 現金収支
= 不足分が資産活用額
```

これは今回の思想に最も合うチャート。

#### チャート3: 特別支出カテゴリ別

60〜72歳の特別支出をカテゴリ別に積み上げ表示する。

カテゴリ:

- 楽しみ
- 生活維持
- 住宅・車
- 医療・介護
- 家族支援

目的は、「資産を生活維持ではなく、自分が望む楽しみに使えているか」を見ること。

#### チャート4: NISA実行・未実行・残り枠

年次で以下を表示する。

- NISA実行額
- NISA未実行額
- NISA残り生涯枠

これにより、資金不足で入れられないのか、枠がないのか、どちらなのかが分かる。

#### チャート5: 普通口座オプションの見える化

既に詳細表示はあるが、比較用に簡易チャートを置く。

- 申告対象損益
- 口座内積上
- 普通預金へ移動
- 税社保増分
- NISA実行額差
- NISA未実行差

## 6. 比較タブ改善

### 6.1 現状の課題

比較タブは情報量が多く、本人が見たい意思決定情報と、原因調査用の詳細情報が混ざっている。

### 6.2 上段に残す主要列

比較表の最初の表は、以下に絞る。

| 列 | 目的 |
| --- | --- |
| シナリオ | 対象 |
| 基準との差分要約 | 何が違うか |
| 資産寿命 | 枯渇しないか |
| 90歳残高 | 最終余力 |
| 目標との差額 | 500万円目標などとの差 |
| 60〜72歳 資産活用額 | 健康寿命期に資産を使った額 |
| 72歳時点残高 | 使った後の安全性 |
| 楽しみ支出 | 望む支出に使えているか |
| NISA実行額 | 投資が実行できているか |
| NISA残り枠 | 枠不足かどうか |

### 6.3 詳細比較は折りたたみ

以下は折りたたみでよい。

- 不足補填売却
- 収入化した原資
- 計画取り崩し
- 追加投資
- 普通口座から現金・普通預金へ
- 税社保増分
- NISA未実行差
- 証拠金不足停止

詳細は必要だが、常に見えていると判断の邪魔になる。

## 7. 特別支出カテゴリ

### 7.1 予備・想定外は外す

予備・想定外は、想定外をあらかじめ特別支出として入れる概念が分かりにくい。

今回の本人用アプリでは外す方が自然。

緊急予備資金は、特別支出ではなく「流動資金最低保持額」に含める。

現状コード上も、カテゴリは以下に整理されている。

- 楽しみ
- 生活維持
- 住宅・車
- 医療・介護
- 家族支援

### 7.2 家族支援の使い方

家族支援は、家族のために意図して支払うもの。

例:

- 親の葬儀費用
- 子どもへの援助
- 家族の引っ越し支援
- 家族イベントへの支出

親の葬儀費用は「家族支援」でよい。

医療・介護は、医療・介護サービスそのものへの支出に寄せる。

## 8. 税・社会保険まわりの注意

税社保の構造は、本人用の比較シミュレーションとしてはよくできている。

ただし、制度値は年度で変わるため、以下の表示が必要。

1. 税社保計算の年度ラベル
2. 料率が何年度前提か
3. 自動計算・手入力・自動+補正のどれか
4. 普通口座オプション利益が申告所得として翌年に入ること
5. 反復計算が収束しなかった場合の警告

特に「普通口座オプション利益」は、口座内に残していても申告対象損益として税社保に影響する。ここは説明を残すべき。

## 9. 今回やらないこと

以下は重要だが、今回の本人用完成版では後回しでよい。

- 他者向け初回ウィザード
- サンプルデータと実データの切り替えUI
- 汎用的な自治体選択
- 用語集つきヘルプ
- 入力補助チュートリアル
- 他社が初見で操作できるナビゲーション再設計
- アカウント管理、クラウド保存、共有機能

今回の目的は、本人が現在の資産・収入・特別支出・NISA・普通口座オプションの関係を誤解なく判断できる状態にすること。

## 10. 実装優先順位

### 優先度A

1. 比較タブに任意の基準シナリオ選択を追加
2. シナリオ差分パネルを追加
3. ダッシュボード上部に「基準との差分要約」を追加
4. 「資産活用額」と「取り崩し」の説明を分離
5. 比較表の主要列を絞る

### 優先度B

1. 60〜72歳 資産活用ウォーターフォールを追加
2. NISA実行・未実行・残り枠チャートを追加
3. 特別支出カテゴリ別チャートを追加
4. ダッシュボードの資産残高チャートを同一スケール比較に対応

### 優先度C

1. 税社保制度値の年度ラベル表示
2. 税社保反復計算の収束警告
3. オプション利益の申告対象・口座内積上・現金化の説明強化
4. データ入出力タブの整理

## 11. 完成イメージ

本人用完成版のトップ画面は、次の順で読める状態にする。

1. 今選んでいるシナリオは何か
2. 基準シナリオと何が違うか
3. 資産寿命は問題ないか
4. 60〜72歳で資産をどれだけ活用したか
5. そのうち楽しみにどれだけ使えているか
6. 72歳時点、90歳時点で安全性は残っているか
7. NISAはどれだけ実行でき、残り枠はいくらか
8. 必要な場合だけ、税社保・普通口座オプション・月次詳細へ潜る

この流れになれば、本人用アプリとしては「見る順番」と「数字の意味」がかなり明確になる。
