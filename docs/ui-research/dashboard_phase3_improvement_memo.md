# フェーズ3 ダッシュボード改善メモ

## 目的

ダッシュボードは、入力値や細かい収支をすべて並べる画面ではなく、退職後の資産活用について次の点を短時間で判断できる画面にしたい。

- 資産が最後まで持つか
- 90歳時点でどれだけ残るか
- 60〜72歳でどれだけ資産を活用したか
- その資産活用が、生活維持だけでなく楽しみ支出にも使えているか
- NISA投資がどれだけ実行でき、残り枠がどうなっているか

目的は「資産を減らさないこと」ではなく、資産を自分の意図した用途に使えていて、それでも将来資産が維持できるかを判断すること。

## 現状の課題

現在のダッシュボードは表示項目が多く、似た意味の指標や、すでに設定済みで認知済みの情報が並んでいる。そのため、重要な判断ポイントが埋もれやすい。

特に次の点を整理したい。

- 同じ意味合いの情報が複数カードに分かれている
- 入力済みの前提情報が主要カードとして表示されている
- 「自由資金」のマイナス表示が、悪い不足額のように見えやすい
- 資産を何に使ったか、特に楽しみ支出に使えているかが見えない

## 削除・統合したい項目

### 1. 資産寿命と90歳時点残高は統合する

現在の表示:

- 資産寿命: 期間内は維持
- 90歳時点残高: xxxx万円

この2つは同じ判断軸なので、1つのカードにまとめたい。

表示案:

- 資産寿命: 期間内維持 / 90歳時点 xxxx万円
- 90歳時点残高 xxxx万円（期間内維持）

### 2. 自由資金の年平均は不要

現在の表示:

- 60〜72歳 自由資金
- 60〜72歳 年平均

年平均は意思決定上あまり使わないため、削除候補。累計額だけで十分。

### 3. 最低流動資金と最低保持額は不要

現在の表示:

- 60〜72歳 最低流動資金
- 流動資金（現金・普通預金）最低保持額

最低保持額はユーザーが設定済みで認知している内容。最低流動資金も設定値に張り付いているだけなら、ダッシュボードの主要指標としては不要。

必要なら詳細画面や設定画面に残す。

### 4. 現在総資産と対象資産は統合する

現在の表示:

- 現在総資産
- サブ表示で対象資産

1カードで十分。除外資産や負債を含む/含まない差が重要な場合だけ、サブ表示に残す。

### 5. 月平均生活費は主要カードから外す

生活費は入力済みの前提情報なので、結果判断の主役ではない。残す場合も、主要カードではなく補助情報や詳細側でよい。

### 6. 月平均取り崩しは整理する

月平均取り崩し、自由資金マイナス、資産活用額が並ぶと意味が重複して混乱する。

今回見たいのは、資産からいくら使ったかと、それでも将来残高が維持されるか。

そのため、月平均取り崩しは削除または詳細側へ移し、ダッシュボードでは「60〜72歳 資産活用額」を主表示にしたい。

### 7. 月平均現金収入・月平均追加投資は優先度低

収支内訳としては有用だが、ダッシュボード最上段に常時出すほどではない。必要なら収支詳細やグラフ下の補足へ移す。

### 8. 最大赤字月は詳細側へ移す

単月の最大赤字は詳細分析向き。資産寿命や期間末残高が維持されているなら、ダッシュボード上の重要度は低い。

### 9. 世帯人数・選択シナリオは主要カードから外す

これは結果指標ではなく前提確認情報。ヘッダーや基本情報タブにあれば十分。

## 自由資金の見せ方を変更したい

現在の表示:

- 60〜72歳 自由資金 -2,772万円
- 補足: 追加投資は差し引かない

この表示だと「悪い不足額」に見えやすい。

しかし、ユーザーの考え方としては、資産があるならそこから取り崩して使えるものは使う、というもの。資産寿命や将来残高が維持できているなら、このマイナス額は問題ではなく、資産を活用した額として見たい。

改善案:

- 60〜72歳 資産活用額 2,772万円
- 補足: 現金収入等で足りず、資産から補った生活・特別支出

「自由資金」というラベルは誤解を招くため、以下のような名称を検討したい。

候補:

- 資産活用額
- 生活資金取り崩し
- 収入超過支出
- 生活後資産活用額

## 資産活用額の内訳を見せたい

単に生活費・税社保・特別支出をまとめるのではなく、何に使ったかを見えるようにしたい。

資産活用の有効性を見るには、生活費として括るだけでは不十分。特に、旅行・趣味・レジャーなど、自分の楽しみのために使えているかが見えると、資産を有効に使えているか判断しやすい。

分類案:

- 基礎生活費: 住居、食費、水道光熱、通信、保険、通常医療など
- 税社保: 税金、社会保険料
- 楽しみ支出: 旅行、趣味、レジャー、家族イベントなど
- 大型予定支出: 車、リフォーム、家電、引越しなど
- 医療・介護 / 想定外支出: 医療増、介護、予定外修繕など

特別支出にはカテゴリを持たせたい。

特別支出カテゴリ案:

- 楽しみ
- 生活維持
- 住宅・車
- 医療・介護
- 家族支援
- 予備・想定外

## 整理後のダッシュボード案

主要カードは以下くらいに絞りたい。

- 現在資産
- 資産寿命 / 90歳時点残高
- 60〜72歳 資産活用額
- うち楽しみ支出
- うち生活補填
- うち税社保
- 72歳時点残高
- NISA実行額 / NISA残り枠

詳細側やグラフ側に回す項目:

- 月平均生活費
- 月平均取り崩し
- 月平均現金収入
- 月平均追加投資
- 最大赤字月
- 最低流動資金
- 流動資金最低保持額
- 世帯人数
- 選択シナリオ

## 判断したいこと

最終的に、ダッシュボードでは次を判断できるようにしたい。

- 資産は最後まで持つか
- 90歳時点でどれだけ残るか
- 60〜72歳でどれだけ資産を活用したか
- その活用額のうち、楽しみ支出にどれだけ使えているか
- それでも72歳時点・90歳時点の資産が維持できているか
- NISA投資はどれだけ実行でき、残り枠がどうなっているか

## 実装上の補足

- 「自由資金」がマイナスの場合、そのままマイナス表示するのではなく、資産活用額としてプラス表示する案を検討したい。
- 「追加投資は差し引かない」という考え方は維持してよい。NISAや特定口座への追加投資は消費ではなく資産内の置き換えなので、生活・自由支出とは分けて見る。
- 特別支出カテゴリが入ると、資産活用額のうち「楽しみ支出」がどれだけあったかを集計できる。
- ダッシュボードは入力確認ではなく、意思決定画面として整理したい。
