# 退職後生活シミュレーション 操作手順書

対象バージョン: 本人専用実用版

## 1. まず最初にやること

1. ブラウザでアプリを開きます。
2. 画面右上のシナリオ選択で、基準にしたいシナリオを選びます。
3. まずは「ダッシュボード」で、サンプルデータの結果が表示されていることを確認します。

## 2. 画面の見方

このバージョンは、上部のタブで各入力画面を切り替える構成です。

- ダッシュボード: 主要指標と資産推移の概要を見る
- 基本情報: 生年月日、開始年月、終了条件、指定年齢残高を設定する
- 初期資産: 現金、預金、証券、負債などを入れる
- 生活費: 月平均の生活費を費目別に入れる
- 収入: 年金、就労収入、投資由来の定期入金などを入れる
- 税・社会保険: 年度ごとの手入力値を入れる
- 特別支出: 旅行、修繕などの単発支出を入れる
- シナリオ: 複製、削除、比較対象の切り替えを行う
- 結果: 月別収支表と年別収支表を見る
- 比較: 複数シナリオを横並びで比較する
- データ: JSON保存、JSON読込、CSV出力を行う

## 2.1 このアプリは

本人の老後資金を、月次ベースで見積もるためのシミュレーションアプリです。

- 生活費、収入、税・社会保険、資産残高、iDeCo受取、追加投資をまとめて確認できます
- まずは本人専用の実用版として使い、将来の一般化や外販にもつなげられる構造にしています

## 3. 基本的な使い方

### 3.1 基本情報を入れる

1. 「基本情報」タブを開きます。
2. 生年月日を設定します。
3. シミュレーション開始年月を設定します。
4. 終了条件を「年齢まで」または「指定年月まで」から選びます。
5. 必要なら終了年齢、終了年月、居住自治体、配偶者有無、メモを入れます。
6. 指定年齢時点の残高を見たい年齢を入力します。
7. 現金を一定額残したい場合は「現金最低保持額」を入れます。
8. 世帯単位で使う場合は「世帯情報」で居住自治体、世帯主、世帯メンバーを入れます。

### 3.2 初期資産を入れる

1. 「初期資産」タブを開きます。
2. 現金、普通預金、定期預金、NISA非課税口座、特定口座、普通口座（オプション用）、iDeCoを入れます。
3. 取り崩し対象外資産と負債残高も必要に応じて入れます。
4. 画面下で、初期総資産とシミュレーション対象資産を確認します。

### 3.3 生活費を入れる

1. 「生活費」タブを開きます。
2. 住居費、食費、医療費などの月額を入れます。
3. インフレを使う場合はONにします。
4. 生活費インフレ率、医療費上昇率を必要に応じて調整します。
5. 年齢別の生活費変更を使うと、満年齢ごとに費用を変えられます。
6. 倍率指定は、その時点の生活費に対する倍率です。

### 3.4 収入を入れる

1. 「収入」タブを開きます。
2. 必要なら「追加」を押して収入イベントを増やします。
3. 名称、世帯メンバー、種別、開始年月、終了年月、月額、課税区分、原資資産を設定します。
4. 終了年月を空欄にすると継続扱いになります。
5. 年金がある場合は、開始年月を年金受給開始月に合わせます。
6. iDeCo受取は、原資資産を iDeCo にすると、受取額が現金に入り、同時に iDeCo 残高が減ります。

### 3.5 税・社会保険を入れる

1. 「税・社会保険」タブを開きます。
2. 年度ごとに、住民税年額、所得税年額、国民健康保険料年額、国民年金月額などを入れます。
3. 変わる年度だけ入力します。
4. 未入力の年は、直近の入力年度を引き継いで計算します。
5. 毎年すべての項目を入れ直す必要はありません。

### 3.6 特別支出を入れる

1. 「特別支出」タブを開きます。
2. 旅行、修繕、家電買替などを1件ずつ追加します。
3. 年月と金額を入れます。
4. その月だけ費用として反映されます。

## 4. シナリオの使い方

1. 画面上部のシナリオ選択で基準シナリオを選びます。
2. 「複製」を押して、別条件のシナリオを作ります。
3. 生活費や収入を変えて、比較用の条件を作ります。
4. 「シナリオ」タブで、比較対象に入れるかを切り替えます。
5. 「比較」タブで、枯渇時期、指定年齢残高、累計取り崩し額を見比べます。

よく使う比較例:

- 現状ケース
- 月5万円または月10万円の追加入金ケース
- 生活費を10%下げたケース
- 特別支出を入れたケース
- 利回り0%と利回りありの比較

## 5. 結果の見方

### 5.1 ダッシュボード

- 現在総資産
- 月平均生活費
- 月平均取り崩し額
- 資産寿命
- 指定年齢時点残高
- 選択中シナリオ

### 5.2 結果タブ

- 月別収支表: 1か月ごとの収入、生活費、特別支出、税社会保険、運用益、取り崩し、残高を確認
- 年別収支表: 年間単位での集計を確認

### 5.3 比較タブ

- シナリオごとの枯渇時期
- 枯渇年齢
- 指定年齢残高
- 累計取り崩し
- 月平均取り崩し
- 年平均赤字

## 6. データの保存と読み込み

### 6.1 自動保存

- 入力内容はLocalStorageに自動保存されます。
- 同じブラウザで再度開くと、前回の状態が戻ります。
- デスクトップのショートカットから開き、アプリ上部の「マニュアル」タブでこの手順書内容を確認できます。

### 6.2 JSONエクスポート

1. 「データ」タブを開きます。
2. 「JSONエクスポート」を押します。
3. 現在の全シナリオと設定がJSONで保存されます。

### 6.3 JSONインポート

1. 「データ」タブを開きます。
2. 「JSONインポート」を押します。
3. 以前に出力したJSONファイルを選びます。
4. 読み込むと、シナリオと設定が復元されます。

### 6.4 CSV出力

1. 「データ」タブを開きます。
2. 「月次CSV出力」を押します。
3. 現在シナリオの月次結果をCSVで保存します。

## 7. まず試すとよい順番

1. サンプルのままダッシュボードを見る
2. 基本情報の開始年月と終了年齢を合わせる
3. 初期資産を自分の値に置き換える
4. 生活費を自分の月額に直す
5. 年金開始月と金額を入れる
6. 税・社会保険を年度ごとに入れる
7. 生活費を上下させた複数シナリオを複製して比較する

## 8. この版での注意点

- 税・社会保険は概算自動計算ではなく、手入力値ベースです。
- 投資収益は、資産ごとの簡易利回りで扱います。
- オプション取引の細かい損益モデルは扱いません。
- 本人利用の意思決定補助を優先しているため、制度の厳密再現より比較のしやすさを優先しています。
- 追加投資は現金と収入から賄い、不足時は預金や投資資産から補います。
- iDeCo受取は、収入として現金に入り、同時に iDeCo 残高を減らします。
- 取り崩しは、現金最低保持額を下回る場合に、普通預金 → 定期預金 → 特定口座 → 普通口座（オプション用） → NISA → iDeCo の順で補います。
- 世帯ベースの税・社会保険自動計算は、世帯メンバー情報を前提に今後拡張します。

## 9. トラブル時の確認

1. 画面が真っ白なら、ブラウザを再読み込みします。
2. 入力値がおかしい場合は、数字が空欄や文字列になっていないか確認します。
3. JSON読み込み後に崩れた場合は、サンプルに戻してから再入力します。
4. 資産がすぐ枯渇する場合は、開始年月、収入イベント、税社会保険、生活費の設定を見直します。
