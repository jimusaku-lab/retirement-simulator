# 人生資産シミュレーション β

税・社会保険、資産形成、資産活用、タイムバケットを含めた人生資産シミュレーションのβ版です。

このアプリは、公開中の一般向け版を壊さずに、資産形成期のユーザー向けダッシュボードを追加検証する作業場所です。

## 起動方法

```bash
npm install
npm run dev
```

β版のローカル固定URLは `http://127.0.0.1:5177/` です。

## テスト

```bash
npm test
```

## ビルド

```bash
npm run build
```

## 役割

- `apps/retirement-life-planner`: 本人・夫婦向け安定版
- `apps/retirement-life-planner-public`: 公開中の一般向け版
- `apps/life-asset-simulator-beta`: 資産形成機能を試すβ版
- `apps/current`: 旧版の参照用

## 初期方針

1. 公開中の一般向け版を壊さず、β版はこのディレクトリで分離して進める
2. 税金・社会保険の計算は中核機能として残す
3. 初回入力は一般ユーザーが答えられる項目に絞る
4. 詳細な税社保前提は、通知書や専門家確認に合わせて補正する場所として扱う
5. 結果画面は、税社保後に本当に使えるお金を中心に再設計する
