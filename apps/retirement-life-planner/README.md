# 退職後生活プランナー

税・社会保険、資産活用、タイムバケットを含めた正式版アプリです。

## 起動方法

```bash
npm install
npm run dev
```

正式版の固定URLは `http://127.0.0.1:5175/` です。

## テスト

```bash
npm test
```

## ビルド

```bash
npm run build
```

## 役割

- `apps/retirement-life-planner`: 正式版
- `apps/current`: 旧版の参照用

## 実装工程

1. 現行計算を守る回帰テストを追加する
2. 公的年金等控除テーブルを詳細化する
3. iDeCo一時金と退職所得控除の重複ルールを追加する
4. 所得控除入力を税計算へ反映する
5. 国保・介護・後期高齢者医療を制度別に分ける
6. 申告不要・申告推奨の判定を追加する
7. 税・社会保険タブの根拠表示を拡張する
8. 最後に、表・チャート・説明文の見やすさを改善する

## 改善予定

- 雑所得・税社保バランス最適化ビューを追加する
  - 公的年金の受給開始年齢、iDeCoの受取期間・回数、普通口座オプションの月次利益、NISA未実行繰越を比較パラメータにする
  - 資産寿命、指定年齢残高、年平均税社保、年平均現金収入、生活後余力、NISA実行額を並べて確認できるようにする
  - 収入増で税・社会保険がどれだけ増え、手取りや資産寿命にどの程度効くかを見える化する
