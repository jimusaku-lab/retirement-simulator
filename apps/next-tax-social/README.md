# 税・社会保険強化版

現行版とは別に、税・社会保険の詳細ロジックを段階導入する比較用アプリです。現行版と同じJSONを読み込み、差分を見ながら検証する前提で使います。

## 起動方法

```bash
npm install
npm run dev
```

比較用の固定URLは `http://127.0.0.1:5175/` です。

## テスト

```bash
npm test
```

## ビルド

```bash
npm run build
```

## 役割

- `apps/current`: 現行の安定版
- `apps/next-tax-social`: 税・社会保険強化版

## 実装工程

1. 現行計算を守る回帰テストを追加する
2. 公的年金等控除テーブルを詳細化する
3. iDeCo一時金と退職所得控除の重複ルールを追加する
4. 所得控除入力を税計算へ反映する
5. 国保・介護・後期高齢者医療を制度別に分ける
6. 申告不要・申告推奨の判定を追加する
7. 税・社会保険タブの根拠表示を拡張する
8. 最後に、表・チャート・説明文の見やすさを改善する
